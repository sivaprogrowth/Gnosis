# A slop grenade passes unchecked AI work to others

Handing off AI-generated work without adding value or checking it makes you look productive while forcing someone else to find the mistakes and clean up.

> A "Slop Grenade" is when you let AI produce the work and pass it on without adding any value (including checking it). Someone else has to wade through it, catch the mistakes, and clean up the mess. You save time and look productive but someone else pays for it.
>
