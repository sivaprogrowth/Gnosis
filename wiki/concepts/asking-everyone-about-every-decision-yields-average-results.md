# Asking everyone about every decision yields average results

If you seek others' input on every choice, you will end up doing what everyone else does and getting the same results they get.

> If you ask other people about every decision you make, you're
> going to end up doing exactly what everyone else does and getting
> the same results that everyone else gets.
>
> — [[shane-parrish|Shane Parrish]]
