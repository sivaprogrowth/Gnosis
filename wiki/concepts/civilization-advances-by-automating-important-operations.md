# Civilization advances by automating important operations

Progress comes from increasing the number of important things we can do without having to think about them. Making key tasks automatic frees the mind for other work.

> Civilization advances by extending the number of important operations which we can perform without thinking about them.
>
> — Alfred North Whitehead, An Introduction to Mathematics
