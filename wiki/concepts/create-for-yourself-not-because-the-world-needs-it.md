# Create for yourself, not because the world needs it

Even if the world doesn't need another work, making it can still be worthwhile because the creator needs it for themselves.

> “My mother would always say 'The world doesn’t need another album.’ And I would say, ‘Yeah, you’re right, the world doesn’t need it. But I do. I’m not doing it for out there' (she placed a hand over her heart) 'I’m doing it for in here.'”
>
> — Suzanne Ciani
