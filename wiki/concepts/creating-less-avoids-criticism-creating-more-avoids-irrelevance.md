# Creating less avoids criticism, creating more avoids irrelevance

Making less work protects you from criticism, but making more work is what keeps you relevant. You have to choose which risk to accept.

> If you want to avoid criticism, create less.
>
> If you want to avoid irrelevance, create more.
>
> — James Clear
