# Dwelling on closed doors hides the open ones

When one opportunity ends, others appear. We often miss them because we spend so long regretting the one we lost.

> “When one door closes, another opens; but we often look so long
> and so regretfully upon the closed door that we do not see the
> ones which open for us.”
>
> — Alexander Graham Bell
