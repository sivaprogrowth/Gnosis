# Extraordinary success requires misunderstood choices

Doing what everyone else does yields average results, so getting different results means making choices that look crazy to most people.

> The path to differentiated results looks like madness to the
> masses. As the adage goes, if you do what everyone else does,
> you'll get the same results everyone else gets. Extraordinary
> success requires misunderstood choices.
>
> — [[shane-parrish|Shane Parrish]]
