# Give value before you ask for value

Create what you would want and offer support or love before you need it yourself; giving should come before asking, in work and in relationships.

> Before you ask for readers, write the article you wish you could
> read. Before you ask for the sale, create the product you wish
> you had.
>
> Before you need support, be the supportive friend. Before you
> need love, be the loving partner.
>
> Always give value before you ask for value.
>
> — James Clear

> A simple rule that makes life easier:
>
> Always strive to give value before you ask for value.
>
> — James Clear
