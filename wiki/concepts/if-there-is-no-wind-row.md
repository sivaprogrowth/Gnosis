# If there is no wind, row

When circumstances don't carry you forward, use your own effort. Lack of favorable conditions is no excuse to stop moving.

> If there is no wind, row.
>
> — Virgil (attributed, Latin adage), Latin adage, possibly Virgil: "Destitutus ventis, remos adhibere."
