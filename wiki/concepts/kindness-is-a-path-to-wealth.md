# Kindness is a path to wealth

Building wealth requires working well with others, which is hard if you are unlikable. Even rich people without kindness end up poor in genuine friendship.

> If you want to be rich, then be kind.
>
> It’s hard to create wealth unless you work well with others, and
> it's hard to work well with others if you are unlikable.
>
> Even if you can build wealth without kindness, rich jerks end up
> poor in friendship. You can buy friends, but not good ones.
>
> — James Clear
