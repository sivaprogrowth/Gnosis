# Know what you want, build a system, repeat

A loop for achievement: know your goal, choose a path where it is possible, build a system to improve along that path, trust yourself, enjoy the results, and repeat.

> Know what you want.
>
> Follow a trajectory where what you want is a possible outcome.
>
> Build a system to incrementally improve your ability to follow
> that trajectory.
>
> Trust yourself.
>
> Enjoy the outcomes.
>
> Repeat.
>
> — James Clear
