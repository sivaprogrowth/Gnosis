# Long timelines are a reason to start now

If the only thing stopping you from pursuing a dream is how long it will take, that is a reason to begin immediately. Think long-term.

> If the only reason you're not pursuing a dream is because of the
> length of time it will take to achieve it, you should start right
> now. Think long-term.
>
> — James Clear
