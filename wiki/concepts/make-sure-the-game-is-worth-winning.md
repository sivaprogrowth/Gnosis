# Make sure the game is worth winning

A prompt to check whether the goal you are working hard toward is actually the one worth pursuing.

> Am I climbing the right mountain?
>
> — James Clear

> Are you playing a game worth winning?
>
> — James Clear

> The will to win is wasted if it is directed towards trivial
> affairs.
>
> — James Clear

> Before you worry about how to win the game, figure out whether
> the game is worth winning.
>
> — James Clear
