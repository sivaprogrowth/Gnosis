# Make the first action mindless as a gateway habit

You can't automate a whole process, but you can make its first action effortless, creating a gateway habit that leads into the larger behavior.

> You may not be able to automate the whole process, but you can
> make the first action mindless. You’re trying to build a “gateway
> habit” for a larger behavior or bigger ambition that you’re
> ultimately working toward. Make it easy to start and the rest
> will follow.
>
> — James Clear
