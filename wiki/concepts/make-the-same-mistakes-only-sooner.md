# Make the same mistakes, only sooner

Mistakes are part of a life worth living, so the regret is not making them but making them too late. Act earlier.

> If I had to live my life again, I’d make the same mistakes, only
> sooner.
>
> — Tallulah Bankhead, Tallulah: My Autobiography
