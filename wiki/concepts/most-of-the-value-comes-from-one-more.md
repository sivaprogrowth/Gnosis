# Most of the value comes from one more

Stopping is easy, but pushing for one more rep, step, minute, or revision is where most of the value is created.

> Something I try to teach the kids is the concept of 'one more.'
>
> One more rep. One more step. One more minute. One more revision.
> One more practice test.
>
> It's so easy to stop, but most of the value comes from one more.
>
> — [[shane-parrish|Shane Parrish]]
