# Needing to learn more is a crutch against starting

Use the best idea you have now. Learning never ends, so needing more knowledge is never a valid reason to delay starting.

> Use the best idea you have right now. Claiming you need to
> 'learn more' or 'get your ducks in a row' is just a crutch that
> prevents you from starting. Education is a lifelong pursuit. You
> will always need to learn more. It's not a reason to wait.
>
> — James Clear
