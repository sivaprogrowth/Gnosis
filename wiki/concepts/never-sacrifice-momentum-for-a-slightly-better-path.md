# Never sacrifice momentum for a slightly better path

If a united team is moving well on an acceptable path, keep going rather than halting them for a better route. Redirect gradually instead of stopping mid-march.

> Never sacrifice momentum. I might know a better path, but if
> we've got a lot of momentum, if everyone's united and they're
> marching together and the path is O.K., just go with the flow. I
> may eventually nudge them down a new path, but never stop the
> troops mid march.
>
> — Ben Chestnut, Learn to Love the Job You’ve Got
