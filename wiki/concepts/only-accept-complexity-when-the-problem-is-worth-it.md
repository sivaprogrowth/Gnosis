# Only accept complexity when the problem is worth it

Simple solutions are almost always better. If a solution must be complicated, make sure the problem is important enough to justify it, since much time is wasted building complex fixes for minor problems.

> Simple is nearly always better. But if it's going to be
> complicated, then make sure the problem is worth the complexity.
> A great deal of time is wasted creating complex solutions to
> relatively unimportant problems.
>
> — James Clear
