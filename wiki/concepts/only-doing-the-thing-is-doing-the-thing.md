# Only doing the thing is doing the thing

Preparing, scheduling, planning, announcing, reading about, or criticizing yourself or others are not the same as doing the work. Only actually doing it counts.

> The only thing that is doing the thing is doing the thing.
>
> — Loopy, Things That Aren't Doing the Thing
