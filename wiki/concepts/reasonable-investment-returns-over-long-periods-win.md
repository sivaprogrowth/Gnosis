# Reasonable investment returns over long periods win

Winning at investing is not about fast, large gains but about earning reasonable returns consistently over very long periods.

> “Success in investing isn’t about making a lot of money in a
> short period of time. It’s about earning reasonable returns over
> very long periods.”
>
> — Bruce Flatt, The Knowledge Project podcast

> “If I can be average for 50 years, I’ll end up in the top 3% of
> investors.”
>
> — Morgan Housel, The Knowledge Project podcast
