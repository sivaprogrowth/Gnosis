# Refine work before first impressions are formed

Polishing a book before publication shapes how it is first received. The same revisions in a later edition matter less because the reputation is already set, so timing matters when refining.

> Revising a book before it is published is incredibly useful. The
> extra polish improves the first impression.
>
> Publishing a second edition a few years after publishing, even if
> it involves the same revisions, is less useful. The brand has
> already been established.
>
> Refine at the right time.
>
> — James Clear
