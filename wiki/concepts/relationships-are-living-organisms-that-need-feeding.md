# Relationships are living organisms that need feeding

Relationships need ongoing attention; if you neglect them while focusing only on kids or work, they wither.

> Relationships are living organisms that need attention and
> feeding; if you starve them while focusing only on kids or work,
> they shrivel and die.
>
> — Sue Johnson, The Knowledge Project
