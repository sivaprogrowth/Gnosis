# Replace one-on-ones with larger context-sharing meetings

Instead of one-on-one meetings, use larger meetings so context is shared with everyone at once.

> Stop one-on-one meetings. Use larger meetings to share context
> with everyone at once.
>
> — Vlad Tenev, The Knowledge Project
