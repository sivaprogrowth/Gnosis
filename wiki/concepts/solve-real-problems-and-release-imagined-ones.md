# Solve real problems and release imagined ones

For every problem you face, ask whether it is mostly real or mostly imagined. Deal with the real ones and let go of the imaginary ones.

> For each headache you face, ask yourself, "Is this mostly real
> or mostly imagined?"
>
> Solve the real problems, release the imaginary ones.
>
> — James Clear
