# There is always time for what's important

The problem isn't lack of time but spending it on unimportant things instead of what really matters.

> It’s not that we don’t have time. It’s that we don’t have time
> for the things that are really important. There’s always enough
> time to do what’s really important, but we get caught up doing
> things that aren’t important.
>
> — Larry Winget
