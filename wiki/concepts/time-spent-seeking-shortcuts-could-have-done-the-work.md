# Time spent seeking shortcuts could have done the work

The total time wasted looking for shortcuts and ways to cheat the process often adds up to more than doing the hard work would have taken.

> If you added up all the time wasted searching for shortcuts and
> trying to cheat the process, the hard work could have already
> been done by now.
>
> — James Clear
