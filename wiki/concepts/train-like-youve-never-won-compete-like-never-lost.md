# Train like you've never won, compete like never lost

Treat preparation as though there will be no second opportunity, but when it is time to perform, act with full confidence as if nothing can go wrong.

> Prepare as if this is your only opportunity, and perform as if nothing can go wrong.
>
> — [[shane-parrish|Shane Parrish]]

> I train like I've never won, and I compete like I've never lost.
>
> — Eileen Gu, On Purpose
