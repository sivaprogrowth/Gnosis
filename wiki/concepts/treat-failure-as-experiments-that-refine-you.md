# Treat failure as experiments that refine you

Approach failure like a scientist: each attempt is an experiment and each mistake is a clue. Failing is really a process of refining.

> Treat failure like a scientist.
>
> Each attempt is an experiment. Each mistake is a clue.
>
> You're not failing. You're refining.
>
> — James Clear
