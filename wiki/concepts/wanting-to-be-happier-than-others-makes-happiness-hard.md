# Wanting to be happier than others makes happiness hard

Being happy is easy if that is all you want, but comparing yourself to others makes it difficult, especially since we overestimate how happy others are.

> If you only wished to be happy, this could be easily
> accomplished; but we wish to be happier than other people, and
> this is always difficult, for we believe others to be happier
> than they are.
>
> — Montesquieu, Mes Pensées
