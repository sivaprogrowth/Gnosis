# What single task would make today a success?

Identify a single achievable task that would make today count as a successful day.

> What is one thing you can accomplish today that would make this
> day a success?
>
> — James Clear

> What is one action that would make today a success?
>
> — James Clear

> What is the one task that, if completed, will make today a
> success? What can you do to make it as easy as possible to get
> started?
>
> — James Clear
