# What would this habit look like if fun?

Nearly any habit can be made more fun than it is now. Ask what it would look like if the habit were fun, then do that version.

> Make your habits fun.
>
> This doesn't mean each habit will be the most fun thing in your
> life, but nearly any habit can be made more fun than it is
> currently. Ask yourself, "What would it look like if this was
> fun? What would it look like if meditation or exercise or
> writing—or whatever—was fun?
>
> Find the most enjoyable version of each habit you do.
>
> — James Clear

> What would this look like if it was fun?
>
> — Greg Isenberg
