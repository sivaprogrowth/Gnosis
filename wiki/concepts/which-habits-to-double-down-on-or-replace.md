# Which habits to double down on or replace?

Habits need periodic revision. Ask which habits deserve more commitment this year and which no longer serve you and should be replaced.

> Habits need to be revised from time to time.
>
> Which habits do you need to double down on this year? Which
> habits are no longer serving you and need to be replaced this
> year?
>
> — James Clear

> Habits need to be revised from time to time. Which habits have
> become more important and you need to double down on next year?
> Which habits are no longer serving you and need to be replaced
> next year?
>
> — James Clear
