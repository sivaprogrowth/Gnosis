# Which peaked project should you let go?

Ask yourself which of your ongoing projects has already reached its peak. Consider whether it is time to drop it and start on a new challenge.

> What project are you still working on that has already peaked? Is it time to let it go and begin climbing the next mountain?
>
> — James Clear
