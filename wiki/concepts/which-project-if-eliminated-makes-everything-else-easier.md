# Which project, if eliminated, makes everything else easier?

List all your current projects and find the one whose removal would make the rest easier. Consider whether you have the courage to cut it entirely.

> Write down all the projects you are working on right now. What is
> the one thing that, if you had the courage to eliminate it
> entirely, would make all the others easier?
>
> — James Clear
