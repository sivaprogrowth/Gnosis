## Abstract

This Product Hunt community discussion thread compiles must-have macOS applications as recommended by developers, designers, product managers, and founders. Initiated by a user seeking a clipboard history tool, the thread quickly broadened into a crowdsourced roundup of utilities spanning window management, screenshot capture, app launching, note-taking, browser alternatives, and more. The recommendations skew toward power-user and developer workflows, with several tools appearing repeatedly as community favourites. The thread is valuable as a snapshot of the macOS productivity tool ecosystem as perceived by a tech-forward Product Hunt audience.

## TL;DR

- Community members most frequently recommend [[raycast]], [[cleanshot-x]], and [[obsidian]] as indispensable Mac tools across developer and designer workflows.
- Clipboard management is the central use case driving the discussion, with Maccy, Paste, CopyClip, PasteNow, and Raycast all cited as solutions.
- Window management, screenshot capture, app launching, and always-awake utilities round out the core categories of "can't live without" Mac software.

## Key claims

- **Raycast** is cited by multiple users as an all-in-one replacement for clipboard managers (FlyCut), window managers (Magnet, Rectangle), and launchers, making it the most versatile single tool mentioned.
- **CleanShot X** receives strong consensus praise for features beyond macOS's native screenshot tool: floating screenshot previews, scrolling capture, easy screen/GIF recording, and availability via SetApp subscription.
- **Arc Browser** is highlighted as a refreshing, Chromium-based reimagining of the browser UI/UX that multiple users switched to and never looked back.
- **Obsidian** appears in multiple independent recommendations as the preferred note-taking app.
- **Amphetamine** and **KeepingYouAwake** are both mentioned as keep-awake utilities, indicating this is a common pain point for Mac users.
- **Alfred** and **Launchbar** are cited as powerful Spotlight alternatives with built-in clipboard history, file actions, text transformation, and search capabilities.
- **Homerow** is flagged as a niche but powerful hotkey layer that converts virtually every on-screen action into a keyboard shortcut via a single trigger combination.
- **Homebrew**, **AppCleaner**, and **HiddenBar** appear in one user's comprehensive list as essential developer infrastructure and housekeeping tools.
